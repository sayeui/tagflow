## UI 层关键发现

### 1. 标签树（最关键）
- **实际渲染节点数：1 个**（除"全部文件"按钮外）
- 节点内容：`#500+`（path 类，category 在 UI 上未展示，但 API 已确认）
- **完全没有任何分类分组**（没有"按类型"、"按年份"、"按扩展名"分区）
- 没有展开/折叠箭头（因为只有单层、单节点）

### 2. 顶栏（toolbar）
- 实际元素：`当前查看:全部文件` 文字 + 一个存储库管理图标链接（aria-label="存储库管理"）
- **没有 Grid/List 视图切换**
- **没有搜索框**
- **没有批量选择按钮**
- **没有手动贴标签入口**

### 3. 文件网格交互
- 点击单个文件：**无任何反应**（URL 不变、无菜单弹出、无详情面板）
- DOM 中 `[role="menu"]` / `[role="contextmenu"]` 元素数量：**0**
- FileGrid.vue 源码已确认 file card 仅 `cursor-pointer` 样式，无 `@click` / `@contextmenu` 绑定 → **重命名/移动/删除/下载入口全部不存在**

### 4. 设置 → 资源库（创建表单）
- 字段：资源库名称 / 协议类型 / 物理路径
- **协议下拉展开后只有 1 个选项："本地目录"**（WebDAV 选项在 UI 上根本不存在，比 API 层"暂未实现"更彻底）
- **没有 `.gitignore` 风格的忽略规则字段**
- **没有"根目录忽略层级"配置**（需求 3.2.1 提到的）
- 已配置库显示信息：名称 / 协议 / 路径 / 最后扫描时间，操作按钮：测试连接、触发扫描、删除（**没有"编辑"**）

### 5. 设置 → 安全
- 修改密码表单完整：当前密码 / 新密码 / 确认新密码
- 提示文案"密码长度至少为 6 位"——**与 CLAUDE.md 中"≥ 12 字节"不一致**（前端校验文案与后端实际策略脱节，可能是遗留文案）

### 6. 控制台错误
- 仅 2 条 a11y verbose 提示（`<input>` 缺 `autocomplete` 属性），**无 JS 错误**

## 与 API 报告（nas-verify-report.md）对照

| 维度 | API 报告结论 | UI 实际现象 | 一致性 |
|------|-------------|------------|--------|
| 标签类型只有 path | tags/tree 仅返回 1 个 path 节点 | 侧栏只渲染 `#500+` 一个标签 | ✅ 完全一致 |
| 文件操作 API 未注册 | /api/v1/files/:id 的 DELETE/PATCH 返回 SPA HTML | 文件卡片根本无点击响应、无菜单 | ✅ UI 比 API 更彻底地"没有" |
| WebDAV 未实现 | protocol:"webdav" 返回 "暂未实现" | 协议下拉根本没列出 webdav 选项 | ✅ UI 提前隐藏了 |
| 缩略图 404 | 6 个 file id 全 404 | 文件网格全是占位图标，无缩略图加载失败抖动 | ✅ |

**UI 独有发现（API 层看不到的）**：
1. 顶栏 Settings 入口仅 1 个图标，导航不直观（"安全设置"在顶部 nav，"资源库管理"在主页 toolbar 里）
2. 修改密码前端文案"至少 6 位"与后端"≥12 字节"不符 —— **潜在 bug**
3. 文件卡片有 `cursor: pointer` 样式但点击无反应 —— **误导性 affordance**

## 结论

UI 层与 API 层、代码静态分析三层结论 **100% 吻合**，无意外功能、无 phantom UI。

代码盘点中"应缺失"的功能在 UI 上确实都不存在，且部分比代码层推断更彻底（WebDAV 在 UI 上连选项都没有，文件操作连点击响应都没有）。

**新发现的两个小 bug**（不影响主功能但应记录）：
1. 安全设置页密码长度文案与后端策略不一致
2. 文件卡片有 pointer 样式但无点击行为（UX 误导）
